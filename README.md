# Freedom Music

Локальный MP3-плеер на Flutter (Windows).

## Идея

- Папка `music/` рядом с приложением — ваша библиотека
- **Источник правды** — метаданные файла (ID3 и т.п.)
- Одинаковые artist + title = **один трек** (альбом и длительность не входят в ключ)
- В БД (`data/library.db`) — индекс после скана, плейлисты, прослушивания
- Скан **не** при каждом запуске (по умолчанию), а по кнопке в Настройках

## Меню

| Раздел | Что делает |
|--------|------------|
| Главная | Кнопка Play — случайный порядок по всей библиотеке |
| Жанры | Группы по жанру из метаданных |
| Исполнители | Страница исполнителя с треками |
| Чарт | Топ-200 за всё время / год / месяц |
| Плейлисты | Создание и прослушивание |
| Настройки | Скан `music/`, опция скана при запуске |

## Запуск

Нужен [Flutter SDK](https://docs.flutter.dev/get-started/install/windows) и **режим разработчика Windows** (для symlink плагинов).

```bash
# если Flutter в C:\flutter
set PATH=C:\flutter\bin;%PATH%

flutter pub get
flutter run -d windows
```

Положите mp3 в `music/` (рядом с exe при релизе, или в корне проекта при `flutter run` — рядом с `build\windows\...` смотрите путь в Настройках).

При `flutter run` папки `music/`, `data/`, `covers/` создаются **рядом с exe** в `build\windows\x64\runner\Debug\`.
