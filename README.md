# Freedom Music

Локальный плеер для Windows. Музыка остаётся в ваших MP3: название, артисты, альбом, год, номер трека, продюсер и текст читаются из файла и туда же записываются.

Нужны Windows 10 или 11, 64-bit, и [Visual C++ Redistributable 2015–2022 (x64)](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).

## Установка

1. Скачайте архив со [страницы релизов](https://github.com/TheSadFreedom/FreedomMusic/releases).
2. Распакуйте **всю** папку, не один `freedom_music.exe`. Рядом с программой лежат библиотеки, без них она не запустится.
3. Запустите `freedom_music.exe`.
4. Положите MP3 в папку `music` рядом с программой. При первом запуске она создаётся сама.
5. В **Настройках** нажмите **Сканировать music**.

Папка `music` указана в настройках. Туда же, в `data`, пишется библиотека приложения: плейлисты, прослушивания, фото артистов. Сами MP3 приложение не переносит.

## Разделы

**Главная.** Кнопка воспроизведения запускает случайный поток по библиотеке. Стоп очищает очередь, чтобы следующий запуск начал новый набор.

**Артисты.** Карточки по числу прослушиваний. На карточке — альбомы, синглы, участие в чужих релизах и популярные треки. Объединение артистов только склеивает карточку: в файлах имя остаётся прежним, поиск находит и старое имя, и имя карточки.

**Продюсеры.** Популярные треки и плейлист на каждого артиста, с которым продюсер работал.

**Чарт.** Слева треки, справа альбомы, за всё время. Места обновляются при запуске и по кнопке обновления, не во время прослушивания. Стрелки показывают изменение с прошлого снимка.

**Плейлисты.**

- **Системные** — «Новинки», «Без метаданных», «Без продюсера», «Корзина».
- **Мои** — свои списки: создать, переименовать, удалить, поставить обложку.
- **Жанры** — группы по жанру из файла.

**Настройки.** Скан, поиск метаданных и текстов, фото артистов, экспорт и импорт данных приложения.

## Прослушивание

Прослушивание засчитывается один раз за запуск трека: после 30 секунд реального прослушивания или после половины длины, что наступит раньше. Перемотка в зачёт не идёт.

Альбом попадает в чарт отдельно. Прослушивания альбома, EP и сингла — сумма прослушиваний входящих треков.

Громкость меняется шагами по 5%. В обычном окне полоска прогресса по верхнему краю плеера, в компактном — по нижнему.

## Метаданные

Одинаковые исполнитель и название — это один трек, даже если файл лежит в двух местах.

**Сканировать music** читает только новые и изменённые файлы и не ходит в интернет. **Сканировать music полностью** перечитывает всё. Скан при запуске по умолчанию выключен.

**Поиск пустых метаданных** смотрит только список «Без метаданных». Трек уходит из списка, когда заполнены альбом, артист альбома, год, номер и число треков. Продюсер записывается, если нашёлся, но без него трек в списке не остаётся. Обложка и жанр при этом поиске не меняются. **Поиск продюсеров** смотрит только список «Без продюсера» и записывает только продюсера.

**Поиск текстов** — отдельная кнопка. Текст берётся из файла, затем ищется в сети и записывается в файл.

Фото, поставленное вручную, кнопка обновления фотографий не затирает.

## Окно и трей

- Кнопка с булавкой включает компактный плеер поверх других окон. Вернуться можно кнопкой разворота в этом окне.
- Кнопка «свернуть» прячет программу в трей. Левый клик по иконке снова открывает окно.
- Правый клик по иконке: открыть окно, воспроизведение или пауза, следующий и предыдущий трек, выход.
- Крестик закрывает программу.

## Данные

**Экспорт** сохраняет плейлисты, фото, обложки плейлистов, историю прослушиваний и настройки. Файлы MP3 в архив не входят.

**Импорт** заменяет эти данные архивом. **Обнулить прослушивания** сбрасывает чарт, плейлисты остаются.
